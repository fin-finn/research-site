# finnwatson.com

The source of a personal research site — writing on credit and financial
markets by Finn Watson.

It is a static site: every page is plain HTML, built ahead of time by
[Eleventy](https://www.11ty.dev/) and served as files. There is no database, no
application server, and nothing on the domain that can be written to.

**<https://finnwatson.com>**

---

## Typeface

The site is set in **Palatine Parliamentary** by Elijah Granet, released under
the LaTeX Project Public License. The original `.otf` files and the licence are
kept in `src/assets/fonts/`. Self-hosting the converted web fonts is permitted
under the LPPL; this attribution is part of that permission and should stay
intact.

## Reuse

The writing on this site is its author's. The code is unremarkable and you are
welcome to read it, but it is published to build the site rather than as a
template for anyone else's.
